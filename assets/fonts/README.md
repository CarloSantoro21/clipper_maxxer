Pon aquí las tipografías de los subtítulos (.ttf/.otf). El render las carga automáticamente.

Por defecto los specs usan **Montserrat Black**. Descárgala gratis (licencia OFL) de
https://fonts.google.com/specimen/Montserrat y copia `Montserrat-Black.ttf` a esta carpeta.

Si la fuente no está, libass usa una de respaldo del sistema y el video se renderiza igual, sólo con otra letra.
